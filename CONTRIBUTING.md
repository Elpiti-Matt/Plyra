# Contributing

Plyra is a research prototype. Reproduce a problem with the included coffee graph or a minimal synthetic JSON file before proposing a change. Include the release, browser, device, view, and exact steps. Do not upload private graph data.

Run `npm ci`, `npm test`, and `npm run build`. For changes to storage, import or exports, add a regression that checks data preservation. For UI changes, record a real browser check separately from DOM unit tests. Keep native node identities and multi-membership stable.

Open an issue before changing the schema, ontology or splitting algorithm. New metrics need a definition and reproducible input; descriptive graph counts are not usability results. Contributors retain their copyright and contribute code under the project MIT license.
