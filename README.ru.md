# Plyra

Исследовательский прототип карты знаний на связанных листах. У одной сущности может быть несколько появлений с собственными координатами. Тело и `id` общие.

**Версия 0.6.1-rc.1.** Обновлены Стопка, Разворот, навигация и добавление узлов. Проходят 55 автоматических проверок, typecheck и сборка. Визуальная проверка в браузере и испытания на реальных телефонах остаются открытыми. [Что изменилось](docs/REDESIGN.ru.md) · [Отчёт проверки](docs/AUDIT.ru.md).

## Открыть

Скачайте `demo/index.html` и откройте в браузере. Внутри уже находятся обе учебные карты. Для открытия демо сервер не нужен; для изменения исходников — `npm ci`, затем `npm run dev`.

На телефоне скачанный HTML иногда открывается просмотрщиком файлов без исполнения JavaScript. В этом случае используйте веб-демо после его публикации на GitHub Pages. Совместимость с конкретными версиями Safari и Chrome ещё нужно проверить.

## Что попробовать первым

Откройте смесь «Утро». У неё три листа: продукт, поставщики, деньги. Перейдите по названиям листов в панели узла, измените тело и убедитесь, что это одна сущность. На узком экране кнопка **Читать лист** открывает список с нормальным размером текста.

На листе «Обжарка» выберите нотацию «процесс». Восемь узлов остаются в графе; три не входят в этот вид. Выбор нотации не удаляет данные. Это небольшой набор фильтров, не реализация стандартной нотации.

Смена режима: **Лист**, **Разворот**, **Стопка**, **Оглавление**, **Одна плоскость**. Листайте стрелками или Alt+←/→; выбирайте названия в ленте над холстом. «＋ Добавить» открывает форму нового узла. Импорт, экспорт и фильтры находятся в «Ещё».

В Развороте выберите 2–6 листов и пропорции. Для трёх есть высокий лист слева; для пяти — широкий посередине. В каждом окне есть собственный выбор листа. Выбор занятого листа меняет окна местами. На телефоне виден один лист композиции; остальные доступны через ленту.

За пунктирной границей видны приглушённые карточки со ссылками на другие листы. Если сущность уже видна на соседнем слое разворота, её внешняя карточка убирается, а линия идёт к ноде. Автоматическая раскладка подстраивается под пропорции слоя. После ручного перемещения или оптимизации позиции сохраняются, а «вписать» подбирает масштаб. Для связи нажмите «связать», затем второй узел или такую карточку. Перетаскивание между холстами как способ создать связь не реализовано.

В Стопке галочками выберите слои. Вернулись наклонные плиты друг под другом, подписи нод и управление расстоянием, наклоном и масштабом. Связи, подписи и золотые линии одного ID включаются отдельно. На узком экране настройки свёрнуты; камера поддерживает панораму и масштабирование.

RU/ENG переводит интерфейс и названия учебных примеров. Название карты закреплено сверху и выделено в центре оглавления. «+» на карточке раскрывает название и тело для редактирования; все появления меняются вместе. Во вкладке **Для ИИ** есть готовый стандарт и скачиваемый JSON-пример, в **FAQ / ЧАВО** — объяснение режимов и действий.

Тонкая рамка отмечает активный слой Разворота. Кнопка **Боковые переходы** скрывает внешние карточки. **Легенда линий** открывается при наведении или нажатии: тонкие сплошные стрелки внутри слоя, пунктир между слоями, бронзово-золотые линии без стрелок для одного ID.

FAQ и вкладка ИИ содержат три короткие мини-GIF и кадры PNG на двух языках. Это учебные иллюстрации интерфейса, не скриншоты браузерного прогона. GIF запускаются вручную. В FAQ также есть пошаговый пример **Одна оплата — шесть моделей** и загружаемый JSON трассировки. [Предложение о связи нотаций](docs/CROSS-NOTATION.ru.md). Нативные редакторы нотаций — следующий этап.

**Оптимизировать расположение** под холстом расставляет ноды с учётом связей на Листе, в Развороте и на Одной плоскости. В Развороте учитываются также линии между открытыми слоями. Позиции сохраняются в JSON и возвращаются кнопкой «Отменить» одним действием; расчёт можно прервать. Это приближённый подбор, а не гарантия отсутствия пересечений. [Алгоритм и ограничения](docs/LAYOUT.ru.md).

## Данные и сохранение

Кофе: 42 узла, 43 связи, семь листов. Депо: 87 узлов, 167 связей, девять листов. Обе карты учебные. Сведения о бизнесе и требованиях не подтверждены источниками.

Импорт: один JSON с `nodes` / `edges` (массив `sheets` можно задать явно) или вместе `nodes.csv` и `edges.csv`. Неправильный файл отклоняется целиком, а текущая карта сохраняется. [Формат и примеры](docs/FORMAT.md).

Браузер сохраняет изменения локально. Экспортируйте JSON для надёжной копии. Есть отмена и повтор последних изменений в текущей сессии; история не переживает перезагрузку. Импорт и замена демо тоже отменяются.

Экспорт «в дерево» оставляет основной лист, но сохраняет рёбра. JSON Canvas создаёт самостоятельные карточки для появлений узла. Внешняя программа не обязана понимать, что их тела должны синхронизироваться. Оригинальный JSON Plyra нужен для возвращения без потерь.

## Разбиение и проверка

«Разбить большие листы» делит переполненные листы на части по их лимитам. Узлы упорядочиваются по ID. Результат детерминирован, но смысл границ нужно оценить вручную. Мультичленство и рёбра сохраняются; координаты на новых листах наследуются.

Линт отмечает переполнение, изолированные узлы, подозрительные членства и другие структурные признаки. Предупреждение не доказывает ошибку предметной модели. [Команды разработчика](README.md#develop-and-verify).

Счётчик после публикации показывает скачивания файлов релиза. Он не считает людей и не встроен в офлайн-приложение. [GitHub, лицензия и сопровождение](docs/PUBLISHING.ru.md).
