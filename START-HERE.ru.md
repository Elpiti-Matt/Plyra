# Plyra 0.7.0-rc.4 — начать здесь

Откройте `demo/index.html` в браузере. Отдельный `Plyra-0.7.0-rc.4.html` совпадает с ним побайтно. На телефоне нужен браузер, исполняющий JavaScript, а не предпросмотрщик файлов.

## Проверить изменения

1. **Листы:** передвиньте узел в редакторе листа. Нажмите «− Все листы» справа сверху. В обзоре есть все листы с узлами, внутренними, межлистовыми и золотыми связями одного ID.
2. Перетащите **лист за заголовок**. Его узлы едут вместе с ним, их внутренние координаты сохраняются. Кнопка «+» в углу листа открывает его редактор. Повторный «−» возвращает к прежнему масштабу обзора.
3. Перетащите **узел внутри листа** в обзоре. Меняется только это появление узла; его появления на других листах сохраняют позиции. За границей листа движение ограничено. Отмена/повтор восстанавливают изменения. Escape во время жеста отменяет незавершённое перемещение.
4. Обзор двигается за фон или колесом; масштабируется кнопками, Ctrl/⌘ + колесом или двумя пальцами. «Вписать все листы» показывает весь проект. С клавиатуры: Tab выбирает заголовок или узел, стрелки двигают, Shift увеличивает шаг, Enter открывает редактор.
5. В обзоре включите **Только для выделенного листа**, нажмите заголовок другого листа: его межлистовые связи и золотые линии ко всем общим появлениям остаются, остальные межлистовые линии скрываются. **Между листами / Один ID** работают независимо. **Разворот:** выберите 2–6 листов для сравнения рядом. Он остаётся отдельным режимом с пропорциями и активным слоем.
6. **Все на один лист:** каждая сущность показана один раз. Передвиньте её, раскройте плюсом и измените текст/атрибут. Позиции исходных листов сохраняются; текст/атрибут меняется у общего ID.
7. **Типы → Листы:** создайте тег и тип, назначьте листу один тип и несколько тегов. **Типы → Атрибуты:** добавьте определение «Стоимость», тип «Число», затем значение к узлу через плюс.
8. **Показ:** проверьте отдельные «Выбрать все / Выключить все» для типов узлов и связей, затем отметьте один тип. Линии приглушаются на месте. Внутри листов они сплошные, между листами пунктирные, между появлениями одного ID золотые. В All-to-1 линии отражают исходные членства.
9. **Стопка:** переключите «Построчно» / «Узлы и связи», группировку по типу или тегу и оптимизацию. **Проект:** импортируйте примеры из `examples/import/`, прочитав ограничения предпросмотра.
10. В **Справка → Подготовить проект с ИИ** проверьте стандарт v3 и пример с шестью типами атрибутов. Скачайте `.plyra`, снова откройте его и проверьте расположение листов в обзоре, All-to-1, атрибуты и импортированную геометрию. Обзорная камера и настройки представлений после перезагрузки сбрасываются; сохранённые координаты остаются.

Результаты автоматической проверки — в `docs/VALIDATION.json`. 98 тестов модели/DOM прошли. Визуальная проверка приложения браузером заблокирована средой; физические телефоны и ручной перенос через внешние редакторы не проверены.

## Сборка и перенос исходников

Для существующего репозитория используйте [UPDATE-GITHUB.ru.md](UPDATE-GITHUB.ru.md). Актуальный архив — `Plyra-0.7.0-rc.4-github.zip`. Инструкция включает удаление старого пути формы Issues, сохранение своих настроек и отдельную публикацию Pages.

Архив содержит один каталог `Plyra/`. Переносите его содержимое в корень своей рабочей копии, сохраняя структуру. Проверьте изменения до коммита; избегайте вложенного `Plyra/Plyra`. `node_modules`, `.qa`, `dist` и история Git не входят в архив.

Для сборки: Node 22.12+, `npm ci`, `npm test`, `npm run build`. Готовый HTML появится в `dist/index.html` и `demo/index.html`, сумма — в `demo/SHA256SUMS`.

Пакет готов для обновления исходников. Push, PR и публикация этой итерации не выполнялись. Файлы сверены с Elpiti-Matt/Plyra, main на 581b3b1; ZIP — снимок нового исходного кода.
