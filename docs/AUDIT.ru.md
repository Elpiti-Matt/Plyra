# Проверка комплекта Plyra 0.7.0-rc.4

9 сентября 2026 года. Комплект сверён с публичным [Elpiti-Matt/Plyra](https://github.com/Elpiti-Matt/Plyra), `main` на коммите `581b3b1fe938c5e274bc1d5904f74d963e4d3e7f`. Проверенный репозиторий содержит 111 отслеживаемых файлов и версию 0.6.1-rc.1. Архив rc.4 продолжает рабочие изменения этой переписки.

## Репозиторий

Прочитаны исходники, README, документация, package/lockfile и workflows. Публичный Checks для HEAD успешен; есть успешная публикация Pages, сайт отвечает. Releases на дату проверки пуст. Закрытые настройки прав, защиты веток и административные параметры Pages недоступны. Сверка относится к указанному коммиту, а не к последующим изменениям.

В main были три устаревших пути: `.github/issue_template/bug_report.yml`, `.github/issue_template/test.txt`, `.github/workflows/test.txt`. Новая форма находится в `.github/ISSUE_TEMPLATE/bug_report.yml`, два пустых файла удалены. Остальные отличия — добавления и замены, перечисленные в [REPOSITORY-UPDATE.json](REPOSITORY-UPDATE.json). Workflows Checks и Pages сохранены без изменения относительно main.

## Приложение и документация

- Добавлены независимые групповые действия фильтров и связи выбранного листа в обзоре, включая прямые линии ко всем общим появлениям.
- Термин «Листы» согласован в интерфейсе и текущих документах; технические имена Canvas и совместимые ключи хранилища сохранены.
- FAQ, промпты, JSON-примеры и учебные GIF используют v3 с атрибутами. Генерация скачиваемых AI-файлов автоматизирована; тест проверяет совпадение с приложением.
- README RU/EN перечисляют возможности, содержат SVG и GIF. Добавлены иллюстрированное руководство FEATURES и подробная инструкция первого обновления конкретного репозитория через GitHub Desktop.
- Обновлены handoff, быстрый старт, описание формата/режимов, публикация и ручная приёмка. Ссылки настроены на Elpiti-Matt/Plyra. Исторический аудит лицензий и измерения сохраняют исходные даты; черновики статей имеют редакторский статус.

## Проверка и её границы

98 автоматических тестов модели/DOM прошли. TypeScript, production-сборка, синтаксис встроенного JavaScript, автономность HTML, ссылки документов, YAML workflows/формы Issues и целостность архива проверяются в итоговом комплекте. Результаты и хеш — [VALIDATION.json](VALIDATION.json).

Визуальная проверка приложения браузером заблокирована средой. Физические устройства и ручной перенос через внешние редакторы не проверены. Схемы и учебные GIF просмотрены отдельно; они не являются скриншотами и не доказывают проверку интерфейса браузером. Ручные сценарии — [QA-MANUAL](QA-MANUAL.md).

Commit, push, PR, release и публикация сайта не выполнялись. Workflows текущего комплекта не запускались на GitHub. [UPDATE-GITHUB](../UPDATE-GITHUB.ru.md) описывает последующие действия владельца.
