# Ручная проверка перед публичным запуском

Статус всех строк: **не выполнено**. Заполнить фактические версии браузеров, дату и результат. Этот файл — протокол, не сертификат совместимости.

| Среда | Проверить |
|---|---|
| Desktop Chrome и Firefox, 1440 × 900 | Пять видов, клавиатура, импорт/экспорт, сохранение |
| Safari на macOS | Локальный HTML, localStorage, изображения data URI, загрузки |
| iPhone Safari, около 390 CSS px | Портрет/альбом, клавиатура, safe area, панорама и pinch, файлы |
| Android Chrome, 360–412 CSS px | Те же сценарии, начало жеста на карточке, отмена касания |
| Планшет 768 и 1024 CSS px | Переключение боковых панелей, Разворот, размеры холста |
| Desktop с текстом 200 % | Нет наложения текста и потери кнопок; панели прокручиваются |

## Последовательность

1. Открыть `demo/index.html`. Проверить первую карту, отсутствие ошибок консоли. При открытии локально в Network не должно быть исходящих запросов. При размещении допустим запрос самой страницы; данные карты отправляться не должны.
2. Найти смесь «Утро» через «Читать лист». Открыть её, изменить тело, перейти на поставщиков и деньги. Тело и ID должны совпасть; координаты — отличаться.
3. Добавить узел через «＋ Добавить», указав имя, тип, целевой лист и заметку; отменить форму без изменений. Создать также двойным кликом по холсту; передвинуть. Отменить/повторить. Создать связь через кнопку и второй узел. Отредактировать направление как исходящий/входящий конец в данных, тип и подпись через панель. Удалить связь, отменить.
4. В Развороте выбрать по очереди 2, 3, 4, 5 и 6 листов. Проверить высокий левый лист у трёх и широкий средний у пяти; ползунок 35–65 %. Выбор занятого листа должен менять окна местами. Проверить линию выбранного узла между листами; общий третий лист не должен её убирать. Проверить переход по внешней карточке к тому же ID. На телефоне — одно окно, с выбором всех листов через ленту.
5. Открыть «Обжарка», нотация «процесс». Счётчик: три исключённых узла из восьми. Вернуть свободный вид; проверить сохранность тел и рёбер.
6. Импортировать `data/broken.json`: текущая карта должна сохраниться, ошибка должна остаться видимой. Импортировать `roastery.json` дважды подряд. Проверить оба срабатывания. Повторить с двумя CSV одновременно.
7. Скачать JSON и загрузить его: сравнить ID, тела, членства и число рёбер. Скачать дерево: предупреждение о пяти потерянных членствах у четырёх узлов кофе. Число рёбер не меняется.
8. Открыть экспорт `.canvas` в Obsidian. Три карточки смеси должны содержать одинаковый Plyra ID. Изменение одной в Obsidian не должно описываться как синхронизация остальных.
9. Включить Стопку: выбрать 2, 3 и все слои галочками, изменить наклон/расстояние, масштабировать. Проверить подписи, переключатели связей и одного ID; выбор ноды должен выделять её отношения. Проверить фокус, создание на активном слое, пустую стопку и возврат всех слоёв. На телефоне проверить разворачивание настроек, панораму и pinch.
10. На телефоне: один палец панорамирует фон, два масштабируют Лист. После отпускания одного пальца не должно быть скачка. Перетаскивание карточки не должно прокручивать страницу. Проверить pointercancel при системном жесте.
11. Клавиатурой открыть и закрыть обе панели; Tab не выходит из модальной панели. Escape закрывает её, фокус возвращается на вызвавший элемент. Скрытые панели не участвуют в Tab.
12. Перезагрузить после правки, после создания пустой карты и сразу после импорта. Проверить сохранность. При запрещённом localStorage должен быть понятен режим «только в памяти».

Скриншоты делать только с учебными данными. На каждый дефект записать шаги, ожидаемое/фактическое поведение, браузер, режим и размер экрана. Блокирующие дефекты сохранения и импорта исправить до основной публикации.

## Дополнения 0.3

- Лента листов прокручивается независимо от холста; стрелки и Alt+←/→ работают, пока не открыта модальная форма.
- Проверьте формы при экранной клавиатуре и повороте. Все поля и кнопки остаются доступными прокруткой.
- В шестилистовый Разворот загрузите одно-листовую карту, затем отмените импорт. Шесть разных окон должны восстановиться.
- Создайте связь между первым и третьим окнами, отредактируйте подпись, отмените. Данные не должны дублироваться.
- Перетащите узел за край окна: линия к полностью невидимой карточке не должна пересекать соседний интерфейс.
- На 360/390 CSS px проверьте ленту и заголовок окна с длинными именами листов; кнопки перелистывания должны оставаться доступны.

## Дополнения 0.4

- RU/ENG во всех режимах, названия примеров, сообщения ошибок, формы; язык после перезагрузки. Исходный экспорт до и после смены языка совпадает.
- «+» раскрывает редактор внутри ноды; имя и многострочное тело меняются во всех появлениях; клавиатура не перелистывает карту во время ввода. Проверить фокус и видимость тела на телефоне.
- «Для ИИ»: копирование, отказ буфера с загрузкой TXT, скачивание JSON, импорт примера и возврат прежней карты через Undo.
- Разворот 2 → 6 → 2: исчезают только внешние карточки с видимой целью. Линии доходят до нод. Проверить контраст, выделение, пролистывание и реальный экран 1366 × 768, 1920 × 1080.
- Для пяти слоёв средний широкий слой использует ширину, а высокий слой в трёх — высоту. Изменить пропорции и размер браузера, затем открыть тело и проверить авторазмещение.
- На 360/390/768 px нет обрезанных обязательных кнопок и горизонтального прокручивания страницы. Название карты, ENG/RU и выбор режимов доступны.

## Дополнения 0.6: оптимизация расположения

- На Листе и Одной плоскости нажать «Оптимизировать расположение»: сравнить наложения, кривые и читаемость до/после, в том числе с раскрытыми телами разных размеров.
- Повторить в Разворотах 2–6, особенно с высоким слоем и широким средним слоем. Проверить общую сцену, пунктирные связи и золотые линии идентичности.
- «Вписать», смена режима, поворот устройства, боковые переходы: сохранённые позиции не должны сбрасываться. Затем повторить оптимизацию под новые пропорции.
- Одним «Отменить» вернуть весь разворот, «Вернуть» — весь результат. Экспортировать JSON, открыть повторно; позиции должны сохраниться. У общей плоскости они независимы от листов.
- На ширинах 360/390 кнопка должна быть доступна отдельной строкой, без горизонтального поиска. Проверить RU/ENG, экранную клавиатуру и доступность «Отменить» сверху.
- На большом файле прервать расчёт кнопкой и Escape. Карта не меняется, фокус возвращается на кнопку; пользователь может продолжить редактирование.
- Проверить первые секунды загрузки с картинками в телах: после измерения высот повторная оптимизация должна учитывать реальный размер карточек.

DOM-тесты покрывают состояния этих действий. Проверка расположения пикселей, реальных жестов и отрисовки кривых остаётся ручной.
