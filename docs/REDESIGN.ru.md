## Поведение разворота

2: два рядом. 3: высокий слева и два справа. 4: сетка 2 × 2. 5: два сверху, широкий посередине, два снизу. 6: сетка 3 × 2. Пропорции — 35–65 %. Выбор занятого листа меняет два слоя местами.

Автоматическая раскладка разворота — представление, она сама не записывает позиции в исходный граф. Перетаскивание сохраняет изменённую позицию и текущую раскладку для вида. Смена состава, размера, пропорций или «вписать» заново подбирает раскладку. Полные связи рисуются по умолчанию; выбор узла выделяет его связи и подписи. Вид можно отключить переключателем связей.

Удаление внешних карточек зависит от реально видимых слоёв. На узком экране отображается один лист, поэтому его переходы к остальным остаются. Внешняя карточка — ссылка, а не дополнительный экземпляр сущности в данных. Несколько маршрутов могут представлять одно ребро, когда это нужно для разных видимых появлений его концов.

## Проверка и границы результата

43 автоматических проверок данных и DOM; typecheck и production build. Проверяются в том числе маршруты, исчезновение внешних дублей, раскладка широкой области, синхронизация редакторов, смена языка без изменения графа, JSON из инструкции, слои и переключатели Стопки.

Визуальная проверка в браузере и на реальных телефонах не выполнена: служба предпросмотра недоступна. jsdom не рассчитывает CSS и не подтверждает удобство жестов. Плотность больших стопок, наложения линий, фактические размеры текста и работа с клавиатурой телефона требуют проверки по `QA-MANUAL.md`. Оценка «вау-эффект достигнут» не ставилась.

## Дополнения 0.5

- Активный слой — рамка 1–1,5 px поверх сцены, не занимающая место.
- Три вида линий: внутренняя тонкая сплошная стрелка; межлистовая пунктирная стрелка; бронзово-золотая линия одного ID без стрелки. У повторных появлений n−1 соединение на n слоёв. Рёбра графа не дописываются.
- Легенда на hover, при фокусе клавиатуры и по нажатию; закрытие Escape и кнопкой.
- Кнопка боковых переходов непосредственно в развороте. Скрытие освобождает место для раскладки; данные и линии между видимыми слоями сохраняются.
- Три темы мини-GIF × RU/ENG, четыре кадра по 2,2 с. PNG и GIF встроены в HTML, есть скачивание и остановка. Иллюстрации осмотрены, но это не браузерные скриншоты.
- Пошаговый пример «Одна оплата — шесть моделей» в FAQ и `CROSS-NOTATION.ru.md`. Это проектная иллюстрация будущих видов; текущий JSON использует карточный рендерер.

## 0.6: кнопка расположения

Добавлена «Оптимизировать расположение» в трёх плоских режимах. Она пробует несколько начальных раскладок с учётом соседей, затем перестановки нод; учитывает прямоугольники карточек и геометрию кривых. В Развороте оценивается общая сцена с видимыми маршрутами и линиями идентичности. На мобильном меняется только открытый слой. [Подробности](LAYOUT.ru.md).

Исправлен сброс авторских позиций Разворота при вписывании и переключении режима. Ручное перемещение сохраняет все показанные позиции листа, чтобы не было возврата остальных нод к старой сетке. Оптимизация сохраняется одним изменением карты; отмена и повтор возвращают весь результат. Плоскость получила независимое поле позиций в родном JSON.
