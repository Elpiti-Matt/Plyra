# Plyra — текущая рабочая версия 0.7.0-rc.4

Режим **Листы** объединяет редактор одного листа и свободный обзор всех листов. «− Все листы» открывает обзор, «+» в углу листа возвращает к редактированию. Листы перемещаются за заголовки, узлы — внутри своих листов. `overviewPos` листа независим от `node.pos` и входит в сохранение/историю.

В обзоре **Только для выделенного листа** оставляет его межлистовые отношения и золотые линии ко всем другим появлениям общего ID. Фокус меняется нажатием заголовка; **Между листами** и **Один ID** управляются отдельно. Все листы и локальные связи остаются видны. В **Показ** две пары кнопок выбирают/выключают все типы узлов и связей независимо; выключенные объекты приглушаются на месте.

**Все на один лист / All-to-1** показывает по одному появлению сущности, позволяет редактировать общие текст/атрибуты и независимо расставлять узлы. Разворот сравнивает 2–6 выбранных листов. Стопка имеет «Построчно» / «Узлы и связи», все узлы, группировку и свою оптимизацию. Словари типов/тегов листов, базовый импорт нотаций и типизированные атрибуты доступны во всех соответствующих редакторах.

Промпты, JSON-примеры и справка согласованы с **Plyra v3**: определения атрибутов, значения всех шести типов, классификация листов и общий ID. Команда `npm run ai:docs` пересобирает скачиваемые файлы, тест проверяет совпадение с приложением. README содержит перечень функций и иллюстрации; [FEATURES](FEATURES.ru.md) показывает работу с ними.

Единственный документ для продолжения — [HANDOFF](../HANDOFF.md). Формат — [FORMAT](FORMAT.md), результаты — [VALIDATION](VALIDATION.json). Содержимое архива сверено с [Elpiti-Matt/Plyra](https://github.com/Elpiti-Matt/Plyra), `main` на `581b3b1`. [Подробная инструкция обновления](../UPDATE-GITHUB.ru.md) рассчитана на первое использование GitHub Desktop. Публикация из этой рабочей копии не выполнялась.

Импорт сохраняет базовую геометрию, но не произвольную графику редакторов; прямого импорта Miro нет. Сплошные внутренние линии меняют визуальную семантику BPMN/UML, поэтому смысл сохраняется в типах/подписях. `.plyra` — формат продолжения работы. Фильтры, камера и расположение стопки — состояние сеанса. Визуальная проверка приложения браузером заблокирована средой; физические устройства и внешний редактор вручную не проверялись.
