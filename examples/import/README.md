# Небольшие файлы для импорта

- `requirements-and-implementation.drawio`: две страницы и соединители.
- `research.canvas`: группа, две текстовые карточки, соединение со сторонами.
- `review.bpmn`: начальное событие, пользовательская задача и поток с BPMN DI.

В меню «Проект» выберите соответствующий импорт и прочитайте предпросмотр. Файлы добавляют листы в текущий проект. После импорта можно назначить текстовые типы отношений и теги, добавить атрибуты и поместить сущность на другой лист. Сохраняйте результат в `.plyra`.
