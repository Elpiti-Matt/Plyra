# Экспорт отчёта: синтетический проект разработки

[English](README.md) | [Русский](README.ru.md)

Пример связывает требования, решения, диаграммы, API-контракт, задачи реализации, планы тестов и документацию. Он создан с нуля: в нём нет реальных людей, компаний, ведомств, адресов или рабочих данных.

Откройте [software-ru.json](../../data/software-ru.json) через импорт Plyra. В обновлённой сборке доступна команда **RU → Проект → Другие форматы и примеры → Пример: разработка**. Загрузка примера заменяет текущую карту и поддерживает отмену; свою работу сначала сохраните в файл.

В графе **40 узлов, 75 связей и 8 листов**. API-контракт — один артефакт на четырёх листах. Документ, диаграмма и описываемая ими сущность имеют разные ID. Размещение одного узла на нескольких листах означает показ одного объекта в разных контекстах.

## Маршрут на три минуты

1. На листе «Контракты и модели» выберите «API-01: контракт экспорта». Через список его листов перейдите к реализации, проверкам и документам: везде это один артефакт.
2. На «Разборе изменения» откройте CHG-01. Перейдите к REQ-03 и найдите вычисление expiresAt, проверку доступа API, очистку и TEST-03. Это кандидаты на пересмотр, а не автоматическое доказательство влияния.
3. На «Документах и фрагментах» выберите «Фрагмент: доступность результата». На него ссылаются две инструкции. Измените текст и посмотрите его на листе разбора изменения. Обновится узел графа; внешние документы автоматически не пересобираются.
4. Сохраните нативный JSON Plyra и откройте его снова: листы, ID и связи сохранятся.

Базовый срок файла — 24 часа после Ready; предложение — два часа для новых файлов. Числа выбраны для упражнения. Предложение ещё не принято. Судьба ранее созданных файлов требует отдельного решения.

## Диаграммы и документы

В [artifacts.md](artifacts.md) находятся таблица API и исходники Mermaid: компоненты, последовательность, состояния. В Plyra они представлены карточками артефактов. Нативного UML-редактора и работающего сервиса экспорта за примером нет.

Карточки тестов — планы проверок, не результаты испытаний. Матрица трассировки задана вручную. «Пакет для обсуждения» показывает состав и порядок материалов; CCMS-сборщик пока не реализован.

## Совместимость

Старый путь `data/depot.json` сохранён для скачивания, но содержит новый синтетический пример. Старое содержимое и переводы его названий удалены из подготовленной версии. История Git, прежние релизы и ранее сохранённые в браузере карты сами от этого не меняются.

RU/EN выбирает полный язык примера при его загрузке. Последующее переключение интерфейса не переводит и не перезаписывает пользовательские тексты. ID и структура русской и английской версий совпадают.
