# Help illustrations

Original instructional UI diagrams, drawn from the Plyra interaction design. These are not browser screenshots or evidence of browser QA.

Three topics × Russian and English. Each GIF has four 2.2-second frames. PNG files are still keyframes; playback in the app is user-initiated.

Rebuild with `python scripts/build_help_media.py` (Pillow and DejaVu Sans required only for asset generation). Project MIT license applies.
